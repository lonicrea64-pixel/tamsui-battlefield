# 驗收測試清單

## 核心流程
1. 打開首頁，確認地圖與古戰場列表可見。
2. 點選任一古戰場點位，確認右側顯示歷史脈絡與關鍵資訊。
3. 選擇答案並送出，確認出現即時回饋與下一步按鈕。

## 錯誤與邊界
1. 呼叫 `GET /api/v1/sites/??` 應回傳 400 與 `INVALID_SITE_ID`。
2. 呼叫 `POST /api/v1/learning-check`，`answerId` 不在選項內，應回傳 422 與 `INVALID_ANSWER`。
3. 後端關閉時，前端應顯示可理解錯誤訊息，不可整頁崩潰。

## 響應式
1. 桌機寬度（>= 960px）確認左右雙欄布局。
2. 手機寬度（< 960px）確認地圖、詳情、時間線改為單欄且可操作。
